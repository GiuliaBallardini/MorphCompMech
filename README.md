# MATLAB Statistical Analysis Guide

## Overview
This repository contains the MATLAB R2024b scripts used to analyze the morphological, compositional, and mechanical properties of hair samples, including whiskers, untreated body hair, and treated root and tip samples.
The analysis includes calculating Pearson's correlation coefficient and computing stepwise forward multiple regression models, including partial correlations (as in Bala et al., 2011).
Additionally, we included the code for plotting the calibration curve fitting (???).
All analyses follow the workflow described in the associated manuscript and are designed for reproducibility and transparency.
