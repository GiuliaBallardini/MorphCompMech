# Statistical Analysis Guide

## Overview
This repository contains the Matlab R2024b and IBM SPSS scripts used to analyze the morphological, compositional, and mechanical properties of hair samples, including whiskers, untreated body hair, and treated root and tip samples.
The Matlab analysis includes calculating Pearson's correlation coefficient and computing stepwise forward multiple regression models, including partial correlations (as in Bala et al., 2011).
Additionally, we included the code for plotting the calibration curve fitting (???).
The SPSS analysis includes the General Linear Model with repeated measures (???).
All analyses follow the workflow described in the associated manuscript and are designed for reproducibility and transparency.
