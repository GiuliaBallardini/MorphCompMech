# Schulz et al.
Code for the analysis performed to investigate the relationships between morphological and mechanical parameters of whiskers, untreated body hair, and treated root and point (from Bala et al. 2011). Specifically, linear regression analysis was employed to calculate Pearson's correlation coefficient (r). 
Then, stepwise forward multiple regression models including partial correlations were used. Values of beta correspond to the standardized regression coefficient if the predictor enters the equation at the next step of the stepwise analysis.
